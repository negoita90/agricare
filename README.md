# AgriCare
PWA mobile-first per la gestione di frutteto e vite.

## Installazione
Pubblicare la root del repository con GitHub Pages, quindi aprire il sito in Safari e scegliere **Condividi → Aggiungi alla schermata Home**.

## Funzioni v1
- dashboard attività imminenti
- schede di pesco, melo, nashi, ciliegio, prugno e vite
- calendario annuale
- guide di potatura con link video
- registro lavori salvato in localStorage
- manifest e service worker per installazione PWA/offline
